# DiveBuddy

Blog subacqueo con voce femminile.

## Stack

- Astro
- Markdown
- Content Collections
- TypeScript
- CSS vanilla
- Sitemap + RSS

## Struttura contenuti

- `src/content/articles`: articoli blog
- `src/content/hubs`: pagine hub
- `src/content/series`: serie editoriali
- `src/content/resources`: checklist e guide rapide

## Comandi

```bash
npm install
npm run dev
npm run build
npm run preview
